BuhTig

Privacy

BuhTig sets no cookies, and it uses no analytics, trackers, ads or scripts from other sites.

What BuhTig keeps

  • Request logs. For each request, the method, the path, the status and how long BuhTig took to answer. Not your IP address, cookies or query strings. Whoever runs this BuhTig decides how long its logs are kept.
  • Fetch counts. GitHub limits how much BuhTig may ask of it, so BuhTig counts how many dashboards each visitor loads from GitHub in an hour. It keeps the counts in memory only, under a hash of your IP address rather than the address itself, and forgets them after an hour or when it restarts.
  • GitHub data. BuhTig keeps the public GitHub data that its dashboards show, so that it need not ask GitHub every time. This data is about repositories and organizations, not about you. BuhTig deletes it after a period that whoever runs it sets, 30 days unless they change it.

Deleting your data

None of this identifies you, so there is nothing of yours to delete.
