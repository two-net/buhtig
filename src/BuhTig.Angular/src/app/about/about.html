About BuhTig

BuhTig turns a GitHub repository or organization URL into a dashboard of its activity, contributors, languages, issues, pull requests and releases. Its name is “GitHub” spelled backwards.

Anyone can explore public repositories. Sign in with GitHub to pin dashboards and refresh data. Add an optional personal access token to see private repositories that token can read.

BuhTig only reads from GitHub. It never changes anything there.

Shortcuts

  • / anywhere but in a text field moves to the search box.
  • Enter opens a dashboard, and Esc clears the search box.
  • In a chart of columns, ← and → read each value, and Home and End go to the first and last. Every chart also has a table view.
  • Replace “github.com” with BuhTig's address in any GitHub link to open its dashboard.

BuhTig is an independent product. It is not affiliated with or endorsed by GitHub.
