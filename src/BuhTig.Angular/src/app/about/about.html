About BuhTig

BuhTig turns a GitHub repository, organization or user URL into a dashboard of its activity, contributors, languages, issues, pull requests and releases. A repository's Activity tab also tells how its stars, forks and open issues and pull requests changed over the last 7, 30 or 90 days, as BuhTig saw them while its dashboard was opened. Its name is “GitHub” spelled backwards.

“Compare with…” on a dashboard puts two repositories, or two organizations or users, side by side, with how each figure differs, down to how actively two repositories are maintained.

“Share card” on a public dashboard copies the Markdown of a card of its figures, for a README, which links back to the dashboard. Links to dashboards show the same card in chats.

“Download CSV” saves a repository list, every page of what matches, in the order shown, or a chart's table, as a file for spreadsheets. Each row has the exact figures, and says when BuhTig read them from GitHub and what they cover.

Anyone can explore public repositories. Sign in with GitHub to pin dashboards, keep watchlists of repositories from any owners, and refresh data. Add an optional personal access token to see private repositories that token can read.

BuhTig only reads from GitHub. It never changes anything there.

Shortcuts

  • / anywhere but in a text field moves to the search box.
  • Enter opens a dashboard, and Esc clears the search box.
  • A tab's name after a repository, organization or user opens that tab, as in “owner/repo pulls” or “org people”.
  • @for (key of paletteKeys; track key) { {{ key }} } on any page opens the command palette. It finds the dashboards you pinned or viewed, and those viewed on this BuhTig lately, as you type; ↑ and ↓ choose one, and Enter opens it.
  • In a chart of columns, ← and → read each value, and Home and End go to the first and last. Every chart also has a table view.
  • Replace “{{ gitHub }}” with BuhTig's address in any GitHub link to open its dashboard.
