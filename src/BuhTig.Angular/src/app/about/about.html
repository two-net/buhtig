BuhTig

About BuhTig

BuhTig turns a GitHub repository or organization URL into a dashboard of its activity, contributors, languages, issues, pull requests and releases. Its name is “GitHub” spelled backwards.

BuhTig only reads from GitHub. It never changes anything there.

BuhTig is an independent product. It is not affiliated with or endorsed by GitHub.

Keyboard

Press / anywhere but in a text field to jump to the search box, and Esc in the search box to clear it. In a chart of columns, ← and → step from one to the next, and Home and End go to the first and last.
